## ثانياً: دليل إعداد API Keys والنشر (API Keys & Deployment Guide)
1. انسخ ملف `.env.example` إلى `.env` على الخادم الآمن.
2. أضف مفتاح `GEMINI_API_KEY` أو `OPENAI_API_KEY` لتفعيل الاتصال الحقيقي بنماذج الذكاء الاصطناعي بدلاً من الوضع التجريبي.
3. أضف مفاتيح `WHATSAPP_ACCESS_TOKEN` و`TELEGRAM_BOT_TOKEN` واضبط عناوين `HTTPS Webhooks` لتفعيل قنوات التواصل الاجتماعي الرسمية.
4. للنشر السحابي على **Google Cloud Run**، استخدم حاوية تشغل الخادم الخلفي مع قاعدة بيانات PostgreSQL سحابية ومخزن أسرار `Google Secret Manager`.
